# Middlewares

Projeto acadêmico desenvolvido durante minha formação técnica em **Desenvolvimento Web e Cibersegurança**, na disciplina de **Segurança e Hospedagem**.

O projeto foi desenvolvido com **Node.js e Express** com foco no estudo e na aplicação de **middlewares** em uma aplicação web.

## Sobre o projeto

Este projeto foi desenvolvido durante uma aula voltada especificamente para o conceito de middlewares.

O professor forneceu o código utilizado na atividade e explicou o funcionamento de cada parte da aplicação. Durante a aula, o código foi reproduzido e acompanhado para compreender como os middlewares são utilizados no fluxo de uma aplicação.

## Objetivo

O principal objetivo da atividade foi compreender:

- O que são middlewares
- Como eles funcionam dentro do Express
- Como são executados durante uma requisição
- Como podem ser utilizados para executar ações antes de uma rota
- Como organizar diferentes responsabilidades utilizando middlewares

## Tecnologias

- Node.js
- JavaScript
- Express

## Conceitos estudados

- Middlewares
- Express
- Rotas
- Requisições HTTP
- Fluxo de execução de uma aplicação
- Funções intermediárias
- Organização de código backend

Projeto desenvolvido como atividade prática durante a disciplina de **Segurança e Hospedagem** da formação técnica.
